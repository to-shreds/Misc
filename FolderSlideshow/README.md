# Folder Slideshow

A small offline Android utility that plays a full-screen slideshow from a local folder selected through Android's system folder picker.

## Included controls

- Time per photo: 1 to 60 seconds
- Fade, slide, zoom, or no transition
- Configurable transition duration
- Shuffle/random playback
- Looping
- Optional recursive subfolder scanning
- Fit-entire-image or fill-screen/crop sizing
- Name, newest-first, or oldest-first base ordering
- Pause/resume, previous, next, and exit controls during playback
- Animated image support when supported by Android

The selected folder is intentionally not persisted. Playback settings are remembered between app launches.
