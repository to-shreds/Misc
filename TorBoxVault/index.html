Save your TorBox key once

Create a small password-protected file so a newly installed TorBox TV app can recover your API key without you having to type it on the Firestick again.

Paste your key from your TorBox account. It never leaves this page unencrypted.

One-time setup

  1. Enter the TorBox key and choose a password above. Download torbox-tv.vault.json.
  2. Upload that file to the root of your apks repository. Replace the previous encrypted file if you are changing keys or passwords.
  3. On a new Firestick installation, select Unlock saved TorBox key, enter your password once, and you're connected.

The file contains only encrypted data. The password isn't saved, and normal app updates keep using the key already stored on your Firestick. If you change your TorBox API key later, make a new file here and replace the old one.
