GET CONNECTED

Your Bluelink account

Connection setup Use the Android app

Download the Android app, install it, and open Santa Fe API Lab. The same tester runs inside the app and sends requests directly to Hyundai. No Tampermonkey or cloud relay is needed.

The app handles your login credentials locally. They are not saved. Sanitized test logs can be exported using Android's file picker.

Manual browser testing

For existing browser-helper users only: the helper extension handles your credentials while sending requests to Hyundai. Ordinary browser requests were blocked in testing. The Android app avoids this extension dependency.

  1. In Firefox for Android, install Tampermonkey.
  2. Open the Santa Fe network helper and choose Install.
  3. Return here and reload. Leave the connection method on Automatic.

Direct requests are useful for diagnostics but may fail with a CORS or network error. That does not by itself mean your login details are wrong.

● Credentials stay in this page's memory and are cleared when you disconnect or reload. Saved logs remove passwords, PINs, tokens, and vehicle identifiers.
