# Comic Library books

Upload your `.cbz` and `.pdf` comics directly into this directory.
The Arcade Comic Library discovers them automatically from the public
`to-shreds/Misc` repository and lists them on its bookshelf.

Name each file as you want the title to appear, such as `Book 01.cbz`.
The reader can also open a local CBZ or PDF without uploading it here.
Only CBZ and PDF files in this folder appear on the GitHub bookshelf.

Note: files committed to this repository are publicly accessible.
GitHub's website upload limit is 25 MiB per file; Git pushes support files
up to 100 MiB. Very large books may need another host.
